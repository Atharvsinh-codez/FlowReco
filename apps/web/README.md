# FlowReco web

FlowReco's Next.js dashboard, sharing surface, and self-hostable web service.

The public origin is configured with `WEB_URL` and `NEXT_PUBLIC_WEB_URL`. The
application does not assume or redirect to a FlowReco-owned hosted domain.

Source, releases, and issue tracking live in the
[FlowReco repository](https://github.com/Atharvsinh-codez/FlowReco).
