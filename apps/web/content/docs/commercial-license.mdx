# FlowReco licensing

FlowReco is open-source software assembled from attributed upstream projects.
There is no separate FlowReco subscription or commercial-license gate in this
repository.

The authoritative terms are the root `LICENSE`, `THIRD_PARTY_NOTICES.md`,
license files shipped with individual packages or crates, and the provenance
record in `docs/UPSTREAM_SOURCES.md`.

Cap-derived code is generally covered by the GNU Affero General Public License,
version 3, while specifically identified crates and third-party components may
use other licenses. Recordly-derived work must retain its applicable notices.
Do not assume one license applies to every file.

For exact source and notices, see
[the FlowReco repository](https://github.com/Atharvsinh-codez/FlowReco).
