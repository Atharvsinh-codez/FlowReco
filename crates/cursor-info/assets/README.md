# FlowReco cursor assets

Every SVG below `mac/` and `windows/` is original FlowReco artwork generated by
`scripts/generate-cursor-assets.mjs`. Platform directory and filenames are kept
only as stable resolver interfaces for recorded cursor metadata; the artwork is
not copied or traced from Apple, Microsoft, Cap, Recordly, or SleekDemo assets.

All cursor art uses a 32 × 32 view box. Resolver hotspots are normalized from
coordinates in that view box and tested in `src/macos.rs` and `src/windows.rs`.
